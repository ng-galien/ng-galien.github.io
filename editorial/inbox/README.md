# Boîte de collecte

Déposer ici les signaux encore bruts, un fichier par événement, nommé
`YYYY-MM-DD-projet-sujet.md`. Copier `../templates/capture.md`, renseigner la
source et laisser l'état à `inbox` tant que la preuve n'est pas qualifiée.

Une fois consolidée dans une fiche projet et éventuellement dans le pipeline,
la capture peut être conservée comme source datée ou déplacée dans un sous-dossier
annuel. Elle ne doit pas être transformée directement en article.

Les témoignages d'agents suivent un autre contrat : ils arrivent dans
`inbox/agents/` par les CI des projets et leur prose est conservée telle quelle.
Ne pas leur appliquer le modèle de capture factuelle ci-dessus.
